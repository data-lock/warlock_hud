# Warlock HUD v0.27.27

This release focuses on settings clarity and polish for World of Warcraft: Forever beta (interface 16001).

## Highlights

- Reorganized settings into clearer pages and grouped tracked auras by their HUD icon slots.
- Replaced icon-size text fields with bounded sliders, visible pixel values, and one-pixel controls.
- Clarified automatic saving and pending HUD updates; added scoped Reset Row and Reset Page actions.
- Improved profile naming, current-profile and dual-spec status, and deletion confirmation.
- Expanded icon tooltips, notification examples, and the Soul Shard deletion warning.
- Added Thorns with group-aware reminders and Unending Breath as an active-only buff at the right end of the Buffs row.
- Fixed the Curses settings preview icon, tightened page spacing, refreshed About, and added one-time `/whub debug` diagnostics.

The secure/native aura tracker and Blizzard cooldown rendering remain in place.

## Install

Download `Warlock_Hud-v0.27.27.zip` from this release and extract it into `World of Warcraft/_classic_beta_/Interface/AddOns/`. The ZIP already contains the `Warlock_Hud` folder. Use `/reload` after updating.

## Verification still needed

The revised Soulstone group announcement still needs a live cast check. The Profiles page and expanded icon tooltips have source checks but have not yet been explicitly confirmed in game.
