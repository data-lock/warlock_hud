# Warlock HUD v0.28.0

This release adds a color preference for the Target DoTs row in World of
Warcraft: Forever beta (interface 16001).

## What's new

- Active target effects are colored and missing effects are grey by default.
- **Tracked Auras > Target DoT colors** lets you switch back to grey active
  and colored missing. The choice is saved in the current profile.
- Fear and the Utility, Buffs, and Procs rows keep their existing appearance.

Thanks to **Tiny** for suggesting the color toggle.

The native aura tracker and Blizzard cooldown rendering remain in place.

## Install

Download `Warlock_Hud-v0.28.0.zip` from this release and extract it into
`World of Warcraft/_classic_beta_/Interface/AddOns/`. The ZIP contains the
`Warlock_Hud` folder. Use `/reload` after updating.
