# Warlock HUD v0.31.0

This release adds a summon request queue and improves HUD layering in World of
Warcraft: Forever beta (interface 16001).

## What's new

- Group members can request a summon by typing `123` in party, raid, instance
  chat, or a whisper. The keyword and accepted sources are configurable on the
  Summons settings page. Only current group members can join the queue.
- A separate movable, resizable window lists requests in arrival order with a
  running wait time, a **Summon** button, and manual removal. A repeated request
  keeps its original place and reopens the window if it was closed.
- The Summon button uses a player click to start the normal summon action. A
  request stays queued until the player arrives nearby or is removed manually.
  The row shows **Pending** when Forever reports an incoming summon offer.
- **Announce** invites requests in the current group channel. Availability and
  successful summon announcements include the current Soul Shard count when
  the client provides it.
- HUD borders, reminder glows, and native buff icons now share the player
  frame's layer, so an open map covers them correctly.

## Testing note

Queue requests, duplicate handling, the Summon button, nearby removal, and
window layout were reviewed in game. The Pending label, instance chat requests,
and the new Soul Shard count wording still need live checks.

## Install

Download `Warlock_Hud-v0.31.0.zip` from this release and extract it into
`World of Warcraft/_classic_beta_/Interface/AddOns/`. The ZIP contains the
`Warlock_Hud` folder. Use `/reload` after updating.
