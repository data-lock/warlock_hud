# Warlock HUD v0.31.1

This update adds default image choices for shared Target DoT slots and improves
the summon queue in World of Warcraft: Forever beta (interface 16001).

## What's new

- On **Tracked Auras**, choose a Bane, Curse, and Drain image independently.
  The choice is saved per profile. **Automatic** keeps the previous behavior of
  using the first available tracked spell.
- The slot's range color checks the selected spell. For example, choosing
  **Drain Life** uses its range instead of Drain Soul's.
- The choice affects the idle image only. Active effects continue to use
  Blizzard's native aura icons and countdowns.
- The Summons page now accepts up to eight comma-separated request words. The
  defaults are `123`, `sum`, and `summ`. Each request must match a word exactly;
  existing custom keywords are preserved.
- **Preview 15 requests** opens a sample queue with varied running wait times
  and several Pending labels. Resize and scroll it to check the layout or take
  screenshots. Its buttons do not cast a spell or send chat messages.
- The queue's X buttons now align with the scrollbar on first open, without
  needing to resize the window.

## Testing note

The DoT selectors, selected-spell range behavior, and summon preview alignment
were reviewed in game. The request word list still needs a live group check.

## Install

Download `Warlock_Hud-v0.31.1.zip` from this release and extract it into
`World of Warcraft/_classic_beta_/Interface/AddOns/`. The ZIP contains the
`Warlock_Hud` folder. Use `/reload` after updating.
