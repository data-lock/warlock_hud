# Warlock HUD v0.32.13

This update fixes intermittent Curse and Bane assignment sync in World of
Warcraft: Forever beta (interface 16001).

- Match addon-message sender names when Forever sends spaces where roster
  names contain hyphens. The mismatch caused valid assignment changes and
  sync snapshots to be rejected.
- Add an **Assignments** recording toggle and **Sync State** button to the
  copyable `/whud trace` window for diagnosing future group sync issues.

The sender-name fix was verified in game with two clients.

Download `Warlock_Hud-v0.32.13.zip` and extract it into
`World of Warcraft/_classic_beta_/Interface/AddOns/`. The ZIP contains the
`Warlock_Hud` folder. Use `/reload` after updating.
