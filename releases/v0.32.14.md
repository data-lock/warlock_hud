# Warlock HUD v0.32.14

This patch fixes a Lua error in the assignment sync trace when a delayed sync
request runs without a group channel, such as just after leaving a group.

The fix was verified in game. Assignment syncing and the copyable trace window
remain available as in v0.32.13.

Download `Warlock_Hud-v0.32.14.zip` and extract it into
`World of Warcraft/_classic_beta_/Interface/AddOns/`. The ZIP contains the
`Warlock_Hud` folder. Use `/reload` after updating.
