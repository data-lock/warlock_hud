# Warlock HUD v0.32.15

This update lets the nonsecure Assignments and debug trace windows close with
their X buttons during combat. Their close handlers now hide the windows
directly. The summon queue retains its protected combat behavior because it
contains secure cast buttons.

The Assignments and trace X buttons were verified in game during combat.

Download `Warlock_Hud-v0.32.15.zip` and extract it into
`World of Warcraft/_classic_beta_/Interface/AddOns/`. The ZIP contains the
`Warlock_Hud` folder. Use `/reload` after updating.
