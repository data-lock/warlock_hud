# Warlock HUD v0.33.0

This release adds Soulstone assignments, drain channel tick markers, more HUD
visibility and color controls, and Shift+Right-click wand attack for World of
Warcraft: Forever beta (interface 16001).

## What's new

- Assign a Soulstone target to each Warlock alongside Curse and Bane. Multiple
  Warlocks can choose the same target. **Clear Assignments** resets all three
  choices. Solo login starts with assignments unset.
- Your Soulstone icon flashes red when your assigned target is confirmed
  missing Soulstone and your stone is ready. Unknown aura status does not
  trigger a warning.
- Drain Life, Drain Mana, and Drain Soul show four interior tick markers on the
  native player castbar.
- Set each HUD row to show or hide out of combat. Hidden rows appear during
  combat and Edit Mode. Choose whether active Buffs icons are colored or grey;
  missing-buff reminders keep their red pulse.
- With a wand equipped, Shift+Right-click a living enemy in the game world to
  target it and start Shoot. Ordinary right-click keeps its normal behavior.
  Use `/whwand` for binding diagnostics.

## Install

Download `Warlock_Hud-v0.33.0.zip` and extract it into
`World of Warcraft/_classic_beta_/Interface/AddOns/`. The ZIP contains the
`Warlock_Hud` folder. Use `/reload` after updating.
