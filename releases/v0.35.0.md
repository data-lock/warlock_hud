# Warlock HUD v0.35.0

This release adds a raid-icon Control assignment for Fear and Banish in World
of Warcraft: Forever beta (interface 16001).

## What's new

- Assign a raid icon, such as Star or Moon, to each Warlock's Fear/Banish
  target. The Control choice appears before Soulstone in the assignments window.
- Compact mode shows the assigned raid marker under a centered Control heading.
- Control assignments sync with group members, appear in assignment
  announcements, and clear with **Clear Assignments**.

The assignment records who handles a marked target. It does not place the raid
marker on an enemy.

## Install

Download `Warlock_Hud-v0.35.0.zip` and extract it into
`World of Warcraft/_classic_beta_/Interface/AddOns/`. The ZIP contains the
`Warlock_Hud` folder. Use `/reload` after updating.
