# Warlock HUD v0.35.1

This update fixes an empty square left in the Buffs row when a group buff such
as Mark of the Wild expires during combat in World of Warcraft: Forever beta
(interface 16001).

When combat makes aura status unreadable, the HUD now keeps the reminder icon
with its border if the relevant buffing class is in your group. Native aura
rendering remains in use. The fix was verified in game with Mark of the Wild.

## Install

Download `Warlock_Hud-v0.35.1.zip` and extract it into
`World of Warcraft/_classic_beta_/Interface/AddOns/`. The ZIP contains the
`Warlock_Hud` folder. Use `/reload` after updating.
