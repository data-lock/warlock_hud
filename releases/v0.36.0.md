# Warlock HUD v0.36.0

This release adds Demonology reminders to the existing Utility and Buff rows
for World of Warcraft: Forever beta (interface 16001).

- The Utility row flashes a red Sense Demons icon when no living demon or active
  Demonic Sacrifice is confirmed. The row recenters as the reminder appears or
  clears.
- Active Demonic Sacrifice effects appear in the Buff row with Blizzard-native
  aura rendering and countdowns, including when a demon is also summoned.
- When Soul Link is known and a demon is present, its Buff row icon flashes red
  if the buff is confirmed missing. An active pet aura uses the native display.
  Unknown aura states do not trigger the reminder.
- Armor and Well Fed reminder glows now pulse only for confirmed missing buffs.
  Their idle colors follow the active-buff color setting.
- `/whud petbuffs` prints a one-time pet buff diagnostic outside combat.

**Known Forever beta issue:** With extra talent points at level 25, Soul Link
could be cast but applied no detectable player or pet buff with either a
Voidwalker or Succubus. The HUD continues to remind while the buff is absent.
Active Soul Link behavior still needs an in-game check at level 30.

The missing-demon alert, Demonic Sacrifice display, row recentering, and buff
color fix were verified in game. The active Soul Link state remains unverified.

## Install

Download `Warlock_Hud-v0.36.0.zip` and extract it into
`World of Warcraft/_classic_beta_/Interface/AddOns/`. The ZIP contains the
`Warlock_Hud` folder. Use `/reload` after updating.
