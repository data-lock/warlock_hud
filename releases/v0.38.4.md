# Warlock HUD v0.38.4

This release adds a dedicated Consumes row and profile sharing for World of
Warcraft: Forever beta (interface 16001).

- Well Fed now appears in the independently movable and configurable Consumes
  row. Existing profiles keep their Well Fed preference and other Buffs settings.
- Export selected profile sections as a copyable code. Preview an import, choose
  the sections to apply, and confirm before changing settings. Codes include a
  format version and are validated before import.
- Reset addon settings to defaults with a confirmation prompt.
- Active Target DoT icons use their cast spell image when the native aura image
  appears as a question mark, while native countdowns remain in place.
- Fix a protected `Button:SetShown()` error triggered by script handlers on
  Blizzard's pooled aura buttons.

The reported protected-frame error was checked in game by the affected player.

## Install

Download `Warlock_Hud-v0.38.4.zip` and extract it into
`World of Warcraft/_classic_beta_/Interface/AddOns/`. The ZIP contains the
`Warlock_Hud` folder. Use `/reload` after updating.
