# Warlock HUD v0.39.0

This release expands the Consumes row for World of Warcraft: Forever beta
(interface 16001).

- Choose which consumables to track: Well Fed, Flask of Supreme Power, Arcane
  Elixirs, Shadow Power, Fire Power and Greater Firepower, Mageblood effects,
  and Wizard Oils. Each category has its own missing-reminder setting. New
  categories are off by default; existing Well Fed preferences are preserved.
- Show active aura effects with Blizzard-native icons and countdowns. Wizard
  Oil uses temporary weapon-enchant state and has no estimated HUD timer.
  Unknown or protected states do not trigger missing reminders.
- Fix group-buff icons flashing when their aura state is unreadable. Reminders
  flash only when a present caster's buff is confirmed missing.
- Fix startup errors from early aura or roster events and retry a deferred HUD
  build when native aura protection permits it. A `/reload` during combat may
  delay the HUD until combat ends.
- Send `/whub debug` output to the copyable trace window.

The consumable trackers were checked in game by the addon author.

## Install

Download `Warlock_Hud-v0.39.0.zip` and extract it into
`World of Warcraft/_classic_beta_/Interface/AddOns/`. The ZIP contains the
`Warlock_Hud` folder. Use `/reload` after updating. If you reload during
combat, the HUD appears after combat ends.
