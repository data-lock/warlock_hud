# Warlock HUD v0.41.0 — Demonic Brand Tracking

Demonic Brand can appear in the Target DoTs row and the optional Multi-Target
tracker when the talent is learned. The addon uses Blizzard-native aura slots
for its countdown and application-count text. It does not calculate or estimate
remaining pet attacks from aura data or combat events.

- The main row has its own Brand tracking and icon-order controls.
- The Multi-Target tracker has an independent per-profile Brand setting, shared
  through profile export and import. It keeps the existing 16-enemy limit.
- Two-enemy tracking, native count and countdown display, profile import, and
  an out-of-combat setting toggle were checked in game.

The filtered aura ID (1293696) comes from beta client data. Talent changes by
respec, two Warlocks branding the same enemy, and reused-nameplate combat cases
have not yet been tested in game.

Download `Warlock_Hud-v0.41.0.zip` and extract its `Warlock_Hud` folder into
`World of Warcraft/_classic_beta_/Interface/AddOns/`. Use `/reload` after
updating.
