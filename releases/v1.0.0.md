# Warlock HUD v1.0.0 — First Stable Release

Warlock HUD 1.0.0 brings the addon out of beta with a complete combat HUD and
the settings, profile, and raid tools built around it.

## Getting Started

- Choose a **Basic** preset for the core combat HUD or **Advanced** to also
  enable Multi-Target DoTs, predicted damage, personal threat, and summon tools.
- New installations see the welcome window while setup is incomplete. Existing
  installations see it on their first launch with 1.0.0. Their saved settings
  stay unchanged unless they select a preset and confirm it.
- Reopen setup later from General settings. All features remain available
  regardless of the selected preset.

## Combat HUD and settings

- Configure Target DoTs, Utility, Consumes, Buffs, and Procs independently,
  with per-row size and position controls.
- Reorder compact icon tiles with their gold grips, enable or hide individual
  icons, and see short labels beneath them. A full HUD demo previews inactive
  and disabled icon slots at their on-screen positions.
- Track Banish separately from Fear and assign either ability to a marked
  target in group assignments.
- Select built-in fonts and sizes for the HUD and Multi-Target window.
- Manage per-profile ordering, visibility, reminders, colors, dual-spec
  switching, and copy, rename, or delete actions. Clicking **Copy** starts
  with the current profile name and adds a duplicate suffix.
- Export selected settings as a copyable code, preview imports, and confirm
  which sections to merge or which profiles to add.

## Warlock tools

- Track target effects, buffs, procs, cooldowns, consumables, weapon buffs,
  stones, and Soul Shards using Blizzard-native aura and cooldown displays.
- View up to 16 Multi-Target rows with native DoT slots, health information,
  optional estimated damage, threat categories, and last-seen rows when the
  client safely exposes the needed unit data.
- Coordinate Curse, Bane, Fear/Banish, and Soulstone assignments with group
  members. The assignment window can be compacted, moved, and resized.
- Queue summon requests, announce availability, and track completed
  Healthstone trades. Trade acceptance and protected spell casts remain manual.
- Receive lower-rank spell warnings and track demon grimoire knowledge at
  trainers.

## Updating

Install the `Warlock_Hud` folder and use `/reload` outside combat. Existing
profiles and Edit Mode positions are preserved. The Getting Started window does
not apply a preset simply by opening or closing; existing profiles show a
confirmation before a preset changes settings.

## Notes

- Multi-Target DoT and threat information is limited by data the Forever client
  exposes safely. Damage totals are estimates, and last-seen health and
  portraits are snapshots.
- The Soul Link missing reminder can remain visible below level 30 if the
  client does not report an applied buff. See the README for details.
- The addon does not inspect restricted aura values or rebuild protected HUD
  elements during combat.
