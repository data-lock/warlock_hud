# Warlock HUD 1.1.0

This release refreshes the Assignments, Summons, and Multi-Target windows with
consistent styling, more compact layouts, scrolling where needed, and separate
scale controls from 50% to 100% on each window's settings page.

## Assignments

- Added a dedicated Assignments settings page with a Group Assignments launcher
  and window scale control.
- Tightened compact mode, improved column spacing, and aligned assignment icons
  beneath their headers.
- The Assignments window remembers that it was open across `/reload`.

## Summons

- Added `/whud summons` as a shortcut to open the summon request window.
- Added clear queue and pending summon counts, class-colored names, scrolling,
  more compact controls, and a separate window scale control.
- The Summons window remembers that it was open across `/reload`.

## Multi-Target DoTs

- Improved which mobs appear in the tracker and how estimated DoT damage is
  presented.
- Added an option to hide DoT icons and a window scale control.
- Reworked rows to give names more room, put threat beneath the name, and place
  DoT icons on the right side of the row.

The secure/native aura display and guarded rebuild behavior remain in place.
