# Warlock HUD v1.1.1

- Add Soul Harvest to the configurable Procs row. The icon tracks the active
  10-second Soul Harvest buff granted when a target dies under Drain Soul.
- Fix Multi-Target window visibility when **Hide outside combat** is enabled,
  and retry initialization when it was deferred for safety.
- Show the 20% execute threshold on the current target frame as well as on
  attackable nameplates, with a smaller marker that stays within the health bar.

The Soul Harvest proc, current-target threshold, and revised MTD visibility
should be checked in game after `/reload`.
