# Warlock HUD v1.1.11

- Detect Well Fed by aura spell ID across client locales, with the existing
  name-based fallback retained for server-specific effects.
- Add Spellstone support to the Weapon Buff tracker. It now recognizes
  Spellstone enchants and displays the matching icon alongside Wizard Oil and
  Firestone tracking.
- Make the missing Weapon Buff reminder default on when no preference is saved.
- Fix tracked-icon checkboxes so each one enables or disables its own tracker.
- Clarify how tracker checkboxes work on Rows & Layouts, Consumes, Buffs, and
  Procs. Reminder controls are described separately from tracker visibility.
- Reduce the vertical size of the Target DoTs and Utility grids so the full
  Rows & Layouts page fits, and align its reset buttons.

After updating, use `/reload`. Enable the desired icons with the top-right
checkboxes in their tracked sections. Check that the Rows & Layouts controls fit
in the settings window and that the Weapon Buff icon changes when an oil, Firestone,
or Spellstone is applied.
