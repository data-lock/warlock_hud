# Warlock HUD v1.1.3

- Reduce duplicate Multi-Target rows in combat by preferring visible nameplates
  when the client restricts names and GUIDs. Target tokens remain available as
  a fallback when no nameplate mob is visible.
- Add an **MTD Rows** button to the debug trace window. It records row sources,
  eligibility, visibility, and any readable or cached identities in the trace.
- Use a slim 6 px gold scrollbar in the Multi-Target, Summon Requests, debug
  trace, and profile-sharing views.
- Improve automatic Healthstone placement retries when trade details or the
  group-member match arrive late. Placement remains optional and only applies
  to an empty trade with a matched group member; trade acceptance stays manual.
- Show a Salvation icon when the client cannot load the buff icon from its
  primary spell ID.

After updating, use `/reload`. Check the MTD rows during a dungeon encounter,
and check scrolling in the Summon Requests and debug trace windows.
