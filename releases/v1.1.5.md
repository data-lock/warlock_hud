# Warlock HUD v1.1.5

- Add an **Enable Buffs row** checkbox to the Buffs settings page. Turn the row
  off to hide player buff icons while keeping the row available in Edit Mode.
- Save the choice with the active profile and include it in profile sharing.

After updating, use `/reload`. Open the Buffs settings page, disable the row,
then enable it again to confirm it hides and returns. The setting takes effect
immediately; no protected HUD rebuild is needed.
